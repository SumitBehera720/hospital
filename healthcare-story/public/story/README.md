# Story video assets

| File | Purpose |
|---|---|
| `story.mp4` | Desktop film. **Currently a labelled placeholder (test pattern with frame counter).** Replace with the real film. |
| `story-mobile.mp4` | Optional 960px-wide version for phones. Enable via `video.mobileSrc` in `src/story/config.js`. |
| `poster.jpg` | First frame, shown while the video loads. |

Encode your final edit with `npm run video:encode -- path/to/final-edit.mov`.
